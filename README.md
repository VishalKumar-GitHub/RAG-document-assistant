# 📄 RAG Document Assistant

A Retrieval-Augmented Generation chatbot: upload PDFs or text files, ask questions, and get answers grounded in your documents with source citations. Built with **Claude**, **FAISS**, and **Streamlit**.

## Features
- Upload multiple PDFs / `.txt` files
- Automatic chunking + embedding (Voyage) into a FAISS index
- Semantic retrieval of the most relevant passages
- Answers generated by Claude, constrained to your documents
- Retrieved sources shown for every answer

## Tech stack
| Layer | Tool |
|-------|------|
| LLM | Anthropic Claude |
| Embeddings | Voyage `voyage-3` |
| Vector store | FAISS (local) |
| UI | Streamlit |

## Run locally
```bash
git clone https://github.com/<your-username>/rag-assistant.git
cd rag-assistant
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

export ANTHROPIC_API_KEY="sk-ant-..."
export VOYAGE_API_KEY="pa-..."

streamlit run app.py
```

## API keys
- **Anthropic**: https://console.anthropic.com
- **Voyage** (embeddings): https://dashboard.voyageai.com

Locally, set them as environment variables. On Streamlit Cloud, use **Secrets** (see below). Copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml` for local secret-file use.

## Deploy on Streamlit Community Cloud
1. Push this repo to GitHub (see below).
2. Go to https://share.streamlit.io → **New app**.
3. Select your repo, branch `main`, main file `app.py`.
4. Under **Advanced settings → Secrets**, paste:
   ```toml
   ANTHROPIC_API_KEY = "sk-ant-..."
   VOYAGE_API_KEY = "pa-..."
   ```
5. Deploy. You'll get a public `*.streamlit.app` URL.
